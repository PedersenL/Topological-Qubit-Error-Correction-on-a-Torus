# Topological Qubit Error Correction on a Torus 

This repository contians a simulation framework for analysis on topological quantum error correction on a torus, comparing toric codes with different stabilizers under biased noise models.

This project was done as part of a 2026 Quantum Ideas Factory at the Abbe Center of Photonics and while the code was written by myself (with AI assistance on the data-analysis), the presentation was made with the help of Rose Lambert-hartmann. We are thankful for the assistance of our advisor Elena.

The Toric code, error correction algorithms and our implimentation are explained in `Toric Code Presentation.pdf` although it usually goes along with explanations of the slides.

## Files

* `toric_code.py`: Contains all simulation, decoding, and data analysis functions.
* `simulation_analysis.ipynb`: Notebook used to run the simulations and plot the results.
* `requirements.txt`: Python package dependencies.
* `.gitignore`: Git ignore patterns.
* `OriginalNotebook.ipynb`: The original notebook with all simulation runs.
* `Toric Code Presentation.pdf`: Presentation slides explaining the project.
